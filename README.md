# Study Hub

A simple, static student resource site for IB and ATAR students. It uses only HTML and CSS, so it can be hosted directly with GitHub Pages.

## Preview locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a new repository on GitHub (for example, `school-study-hub`).
2. Add `index.html`, `ib.html`, `atar.html`, `styles.css`, and this README to the repository.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. GitHub will show the published site address in the Pages settings after deployment.

The site uses relative links between its pages, so it works both at a GitHub Pages project URL and when previewed locally.

## Customize

- Update the links and descriptions in `ib.html` and `atar.html` to match the resources your school recommends.
- Change the site title, school wording, colors, and layout in the HTML and `styles.css` files.
- Check each external resource link and any school rules before sharing the site with students.
